# 三个场景，开始使用借个脑子

不需要先学命令。下面三个场景都可以直接贴给 AI。
人物和记录均为虚构示例，不是用户的真实经历。

## 1. 有件事拿不定主意

你说：

> 我想把自己做手工的过程发成短视频，但总觉得得先买灯、学剪辑。每天只有半小时。你帮我看看第一步怎么做。

从一个今天能完成的动作开始。例如，用现有手机拍一段，先看看自己是否愿意持续记录，再决定是否购买设备。

你可以继续说：

> 就照你推荐的，帮我安排今天这半小时。

这一轮的结果是一份半小时内可执行的安排。

## 2. 同事这招，我也想会

你说：

> 这是一个虚构例子。小周催合作方时会说：“周五要交，周四前需要拿到图片。你今天能给，还是明早能给？如果明早不行，我就先用旧图排版。”我想学他的办法。现在我想请师傅明天下午三点前确认柜子的尺寸，帮我写一句。

得到一句可发送的消息，并从中提炼三步做法：说清时间、给出可选答复、约定无法按时完成时的处理办法。

这份方法来自单个沟通示例。使用时按实际安排填写时间与备选方案，避免作出无法兑现的承诺。

你可以继续说：

> 把这招留给我以后用。名字就叫“把下一步说清楚”。

AI 会生成一份方法草稿，试一个新问题和一个不适用问题，再展示内容请你启用。以后你可以直接说“帮我催一下”，AI 会判断这份方法是否适用。你也可以说“用把下一步说清楚那招”。

## 3. 让 AI 多懂我一点

你说：

> 只看这三条虚构记录，不要读取我其他聊天：一，我不喜欢计划排得太满。二，上次旅游我留了半天空白。三，AI 建议我每天安排六个景点，但我没采用。你觉得我在做选择时有什么习惯？先别保存。

从这些记录中，可以核对一条具体偏好：“安排旅行时，倾向留出自由时间。”未采用的建议不计入个人偏好；这条观察只用于旅行安排。

你可以继续说：

> 这条可以记住，但只用于安排旅游。

确认后，这条偏好只用于旅行安排。之后说“你记了我什么”可查看记录，说“把刚才那条忘掉”可删除记录。

## 不顺手时，直接说

| 你说 | 对应操作 |
| --- | --- |
| 别问了，先给我一版 | 按已知信息先交付 |
| 这次别参考小周 | 本次排除对应方法 |
| 你这次用了谁的办法 | 显示真正加载的方法与分工 |
| 接着上次给客户的那段写 | 查找已保存的同范围任务；找不到就说明 |
| 你帮我整理反馈，发之前给我看 | 生成本地草稿；审阅接收地址和内容后再发送 |
| 检查一下有没有新版 | 展示新版变化；同意后再更新 |
| 不要作者推荐 | 保存关闭设置 |

想指定时再用命令：Codex 用 `$bab`、`$bab-pro`、`$bab-me`、`$bab-ask`、`$bab-help`。Claude Code 的本地 Skill 通常用 `/bab` 等斜杠命令。WorkBuddy 先直接说“用借个脑子帮我梳理”；不同应用以实际显示为准。

自动调用依赖应用实际加载 Skill 和路由规则。浏览器聊天窗口若不能读本地文件，只能使用你主动提供的材料，不能自动看旧会话或保存本地档案。

## 手里有视频、录音、书籍或照片

直接按 [素材提供指南](materials-guide.md) 中对应类型提供。里面有八类材料的说法、读取失败后的替代办法，以及一个完整的虚构会议练习。

不用按顺序学完教程。你有材料就从材料开始，没有材料就让 AI 直接示范一件小事。

## 想下次找得到

提供文件与保存素材是两件事。需要收集时可以说：

> 把这份材料存进我的素材库，标题叫“客户沟通练习”，标签是“沟通”，只用于当前项目。

AI 会展示保存位置和版本，再执行。原件不动，库内只保留当前副本。
以后说“找一下客户沟通练习”即可按标题和标签查找。需要更新就提供新版，并说“更新原来那份”。相关方法会等待复核，不会继续自动沿用旧材料。

素材按标题与标签查找，不含全文或语义搜索。只用于当前任务时，说“先不要保存”即可。
