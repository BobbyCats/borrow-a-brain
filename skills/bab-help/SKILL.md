# 带我上手 · Show Me How

读取 [使用帮助](../bab/references/roles/help.md)。展示“本次使用：带我上手”。

先让用户完成一次有用的小任务，再解释必需的概念。能用自然表达就不要求背命令。安装或维护时只读取所需操作章节。

用户问“你能看到什么”时如实说当前权限与范围。未配置的镜像、官网和反馈服务不能当成已上线能力。
