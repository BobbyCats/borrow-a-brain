# 0.1.12 验证记录

## 修复范围

0.1.11 独立包本身可以运行，但总入口的示例写死了 `node`。没有 Node.js 的新会话会报错，需要用户额外提示独立程序位置。

0.1.12 为五个入口统一使用 `run.sh / run.cmd`。启动器先选包内独立程序，否则检查 Node.js 22+。安装 Agent 按系统和架构选包；没有匹配独立包时准备官方 Node.js。安装范围和依赖变化仍在安装前展示，已有授权不重复询问。
