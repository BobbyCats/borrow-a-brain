## 这次实测改变了什么

0.1.1 的脚本测试通过，但独立的 Codex 新会话在“学同事”和“认识自己”两类自然话语中绕过了 Skill。前者只写消息，漏掉方法学习结果。

0.1.2 因此要求新会话首次读取总入口，再区分主流程。直接执行仍不强迫访谈，但学习任务不能省略方法卡与边界。安装预览也补了路由全文，角色参数补了允许枚举。

恢复场景暴露了模块入口误用和 macOS 路径别名。已增加运行入口指引与 context 命令，统一任务范围。详细实测见 [独立验收](independent-evaluation.md)。

## 保留的判断

- Skill 的文字规则会受宿主与模型影响；没有宿主钩子就不能保证每一轮强制执行。
- 模型试用不等于普通新手完成上手。真实目标用户测试仍需单独做。
- 从有限材料整理同事的方法，不能证明复刻了真人完整判断，也不能代替他的意见。
- 来源、反馈、更新都要保留证据。版本号变大不等于某个用户的问题已经解决。
