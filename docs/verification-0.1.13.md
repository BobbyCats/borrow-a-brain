# 0.1.13 验证记录

本版合并自然接话修订与 0.1.12 的自动启动器。保存、试用、启用和外发确认流程未改动。

## 已有对照依据

语气修订在发布前完成固定三题对照：两个开放讨论场景、一个短消息交付场景。基线与候选各使用全新隔离会话，共六个会话、十四轮输出；模型与推理强度一致。材料为合成案例，不读取用户聊天或方法库。

- 第一题保留了决定判断的反常数据；交流感接近，基线的验证步骤更完整。
- 第二题候选减少了重复和回答负担；基线保留了更多试验细节，候选未出现实质性退步。
- 第三题候选直接交付正文，两版均保留了必要事实。

本轮结论是有限采用：交流方式有所改善，方法价值未见实质退步。文本审阅不等于真实用户偏好测试，也不能证明所有模型和措辞都会改善。轻度粗口属于场景许可，不以出现次数作为得分。本次发布不重跑该对照。
