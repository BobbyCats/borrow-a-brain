# 开发与验证状态

当前发行版本为 **0.1.14 体验版**。可从 [GitHub Releases](https://github.com/BobbyCats/borrow-a-brain/releases/tag/v0.1.14) 或[官网](https://jclab.work/tools/borrow-a-brain/#start)下载。

## 本版变化

收录方法时，按内容建议个人通用或项目专用。可跨项目复用的做法优先建议个人通用，已有方法保持原范围。查询提示注明实际范围，区分暂无可用方法、本次不适用和查询失败。

本次发布沿用已完成的跨项目试用与不适用场景记录，不重跑模型对照。发行包和安装升级检查见 [0.1.14 验证记录](verification-0.1.14.md)。

## 当前支持

- 五个中文入口，按自然语言选择提问、方法提炼、个人经验或使用帮助。
- 方法草稿、试用、确认启用和版本记录；当前任务中的主动收录建议。
- 素材保存与检索、获准历史读取、个人记忆，以及同范围任务恢复。
- 安装预览、规则合并、文件改动保护、签名更新和卸载。
- 确认发送的私有反馈、进展查询、修复版本关联与失败重试。

程序测试检查状态、权限范围与数据一致性。方法是否适用、提问是否有用和成品是否满足任务，还依赖宿主模型。保存成功或格式完整不能代替使用效果。

## 支持与验证的区别

| 项目 | 范围 |
| --- | --- |
| Codex | 已完成部分真实对话与固定场景验证；不保证所有表达和模型均表现一致 |
| Claude Code | 提供安装支持；真实隐式调用与恢复仍待验收 |
| macOS arm64、Windows x64、Linux x64 | 提供独立程序；各版实际构建和安装结果见对应验证记录 |
| 其他架构 | 可使用 Node.js 22+ 通用源码包 |
| 多媒体输入 | 复用宿主工具；能读取哪些格式取决于所用应用 |

普通新手使用、跨宿主交互、操作系统代码签名和 macOS 公证尚未完成全面验收。DeepSeek Harness 适配仍处于设计阶段，未接入运行。

更新检查在使用时执行，没有后台任务。客户端支持多个更新源，官方包目前只配置一个源。国内下载不依赖 GitHub，也不等于已有独立备用镜像。
