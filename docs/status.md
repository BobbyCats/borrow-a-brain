# 开发状态

当前代码版本为 0.1.4，处于预览阶段。官网可下载版本以 [发行清单](https://jclab.top/downloads/borrow-a-brain/releases.json) 为准。

## 已实现

- 五个中文入口、自然语言路由说明、本地能力目录、最多三份方法的分工约束、续聊版本恢复。
- 人物独立目录、来源与方法、版本草稿、确认启用、回退、导出预览和删除。
- 环境发现、获准目录读取、Codex/Claude JSONL 和规范 JSON 导出适配器。
- 候选与确认记忆、范围检索、替代与修订链删除。
- 安装预览、规则块合并、碰撞检测、改动保护和可恢复卸载。
- 可配置地址、签名更新验证、镜像回退、离线继续和保留个人数据。
- 本地反馈预览、确认摘要、服务端认证收件与私有查询、修复版本回执。
- 资源推荐限频和关闭；小惊喜的行为规则。
- macOS、Windows、Linux 独立运行程序构建；Node.js 源码内核。三平台 CI 安装与维护验证已通过。

- JC LAB 工具箱、中文说明、版本页、私有管理界面和生产 API 已接通。
- 0.1.1 安装包注入国内反馈与签名更新源；仓库默认配置仍为空。
- 后台会话、CSRF、状态/版本处理、内部备注隔离、并发修订和每日数据维护。
- Codex / Claude Code 项目安装快捷入口、可审阅的完整规则与安装前冲突检查。
- 同范围任务查找、获准的进度摘要与续聊恢复，规范化项目路径。
- 包内完整练习、版本参数示例、发行许可与运行时来源。
- 独立代理已开展真实 Codex 新会话试用，修复 0.1.1 的隐式调用遗漏，详见独立验收记录。
- 0.1.3 修正进度被重复分工覆盖、多安装检查互相抑制、链接目录越界、安装版本参数漂移和带查询参数的反馈回执地址。分工变化后的旧进度保留并标记待复核。
- 0.1.3 本机 45 项测试、独立复测 12 场景和六项 CI 通过。四种签名分发候选已组装，实际 0.1.1 → 0.1.3 升级保留记忆与原规则；官网尚未切换本版。
