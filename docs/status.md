# 开发状态

当前代码与官网分发版本均为 0.1.5 体验版，已于 2026-10-06 发布。四个平台安装包、签名更新源、GitHub Release 和官网说明已同步。官网可下载版本以 [发行清单](https://jclab.top/downloads/borrow-a-brain/releases.json) 为准。

## 当前优化范围

- 回复质量、素材接入、教程、专属素材库和上轮五项问题已完成本地实现。
- 本机 66 项程序测试通过。18 次真实 Codex 会话覆盖 16 个不同场景，包含两项无 Skill 对照；另有两次图片参数错误在模型启动前失败，已修正测试脚本并重跑。
- 实际读取 PDF、Word、图片、字幕；素材入库、覆盖更新、找回新版与方法草稿保存完成端到端试用。原始音频只验收了缺少转写工具时的降级说明，未证明音频转写或视频画面解读成功。
- 源码与 macOS arm64 独立程序安装维护链通过；实际旧 0.1.4 包升级后，旧方法记录、确认记忆和原规则保留。详见 [0.1.5 验证回执](verification-0.1.5.md)。
- 本版三个系统的源码测试、独立程序构建和安装维护 CI 已通过。四包线上下载、旧公钥验签、正式源码/Mac 包解压后的维护链通过。现有 Codex 用户级安装已由 0.1.4 升至 0.1.5，44 个文件与正式包一致；既有个人资料及其他规则保持不变。
