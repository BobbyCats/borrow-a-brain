# 开发状态

2026-10-05，版本 0.1.1，公开体验安装包，源码仓库保持私有。中文名与 bab 系列短命令已获用户确认。

## 已实现

- 五个中文入口、自然语言路由说明、本地能力目录、最多三份方法的分工约束、续聊版本恢复。
- 人物独立目录、来源与方法、版本草稿、确认启用、回退、导出预览和删除。
- 环境发现、获准目录读取、Codex/Claude JSONL 和规范 JSON 导出适配器。
- 候选与确认记忆、范围检索、替代与修订链删除。
- 安装预览、规则块合并、碰撞检测、改动保护和可恢复卸载。
- 可配置地址、签名更新验证、镜像回退、离线继续和保留个人数据。
- 本地反馈预览、确认摘要、服务端认证收件与私有查询、修复版本回执。
- 资源推荐限频和关闭；小惊喜的行为规则。
- macOS、Windows、Linux 独立运行程序构建；Node.js 源码内核。三平台 CI 安装与维护验证已通过。

- JC LAB 工具箱、中文说明、版本页、私有管理界面和生产 API 已接通。
- 0.1.1 安装包注入国内反馈与签名更新源；仓库默认配置仍为空。
- 后台会话、CSRF、状态/版本处理、内部备注隔离、并发修订和每日数据维护。
