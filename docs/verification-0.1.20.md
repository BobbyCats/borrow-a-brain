## 线上回执

从正式源码包在隔离目录完成新安装，再完成合成任务。发送带验收标记的安装成功与首次任务完成回执，接收端分别收到一次。重复发送被去重。关闭后不再发送。正式回执总数未变化。

本地与 HTTP 测试另覆盖默认关闭、同意要求、首次任务确认门、失败重试、旧安装分类、升级单列、事件及语义去重、未登录接口拒绝、Windows 文件占用有限重试。测试数据独立于正式统计。

## 网站采集验收

官网 7.23.1 已上线。隔离验收站点中，一次页面加载只产生一条浏览记录；复制成功和下载点击各产生一条事件。关闭统计后，刷新与复制没有新增事件。恢复原浏览器偏好后产生一条新的验收浏览记录。验收数据未进入正式站点。

维护者后台实际登录、日期筛选和日志回读通过。Umami 数据备份已在独立数据库恢复，日志 SQLite 完整性与回执副本读取通过。

## 边界

数据按自愿参加的安装实例统计，不代表全量用户或自然人数。没有收到回执不能推定没有安装。跨设备、复制目录、清除安装资料和重复安装会影响实例口径。

网站页面访问、复制成功、下载按钮点击、服务器文件响应和 GitHub 附件下载是不同口径。服务器历史记录从 2026-10-09 起保留；不能据此重建历史安装成功或首次使用，也不能与浏览器访客相加。

原生 CI 和正式包检查不能代替所有宿主的完整用户交互。Claude Code、WorkBuddy 的既有验收边界未改变。本次没有覆盖已安装用户的统计偏好，也没有改写已经发布的历史安装包。
