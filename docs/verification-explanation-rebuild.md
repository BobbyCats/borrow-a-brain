# 问到点上：解释重构验证

2026-10-17。基于 0.1.14 的本机修订，尚未发布。

## 改动

开放卡点按需加载 [解释重构](../skills/bab/references/roles/explanation-rebuild.md)。由 Agent 主动找出旧解释遗漏的观察、拆开默认前提、提出不同机制，并用分辨证据推进判断。

方法提供撤掉前提、切换角色、改变观察尺度、借用异域机制四类动作。按卡点选择，不逐项执行。收束看推导进展，移除默认问题数量提示。复杂研讨保留当前判断状态，沿用已有记录与保存授权。

实际安装变化仅四个文件：提问流程、解释重构、bab-ask 入口、bab-ask 界面说明。运行代码、方法库格式、全局路由与存储机制未变。

## 证据驱动的修订

设备题暴露出“验证局部指标，遗漏原业务目标”的问题。最终稿仅补充一条原则：分辨机制时还要检查用户原目标及转移给其他环节的代价。原始候选、输出和评审保留。

使用设备题原三轮输入，对最终稿再运行一场新会话。它继续主动构造、区分和修正机制；最终撤下已无依据的无人接手与资质解释。验证动作同时检查授权等待、故障至复机总时长和生产损失。该场无持久数据改写。

本轮合计九场、十九轮。最后一场是候选定向回归，不是第二轮旧新版因果对照。
