# 0.1.9 验证记录

验证日期：2026-10-12。状态：**已发布体验版，官网与本机正式包同步完成。**

## 本版范围

- 复用更新检查入口，跟进已发送反馈并区分作者标注、可信可用版本与本机版本。
- 更新检查失败后按 1/6/24 小时退避，成功后恢复七天间隔。反馈查询成功后间隔 24 小时。检查在再次使用时发生。

- 保存、启用、发送反馈和安装更新的确认实现未修改。个人资料与配置保留。

## 已有验收

94 项程序测试和五轮新会话实测通过。实际模型为 gpt-6-astra / ultra；普通写作任务触发检查，断网后到期重试、反馈关联、重复提示抑制及签名失败的表达符合本轮要求。测试使用合成数据及受控网络，没有发送真实反馈。

实现与对话详情见 [反馈跟进与失败重试验收](verification-feedback-update.md)。这些结果只覆盖已测场景，不代表所有模型或宿主均表现相同。
