# 整理一条进度消息

下面用一段模拟进度记录，展示“交付回执对账”方法怎样帮助写清已确认事项、待补材料和时间要求。示例回复来自 Codex 中的借个脑子 0.1.7，方法版本为 v0002。

## 输入

> 以下是虚构材料。帮我把这段进展整理成发给搭档的群消息，明天上午10点要汇总：小册子封面有邮件 C-17 的确认；同事说12页正文排完了，我还没收到 PDF；印厂说纸样备好了，照片还没发来。我要搭档在明天上午10点前把正文 PDF 和纸样照片收齐。简短、好回复。

## 实际回复

> 明天上午10点汇总小册子进展，辛苦你在这之前收齐正文 PDF 和纸样照片。
>
> 已核实：封面已获邮件 C-17 确认。
>
> 待核验：同事说12页正文已排完，PDF 我还没收到；印厂说纸样已备好，照片还没发来。
>
> 请回复：正文｜PDF｜明天上午10点前；纸样｜照片｜明天上午10点前。能按时收齐回“收到”即可；有卡点请说缺哪项、预计几点能拿到。

## 方法怎样用在了这条消息里

“交付回执对账”把消息分为三部分：已确认事项、待补文件、回复期限。方法启用后，可在适合的任务中自动选用。

正文保留了“同事说已排完”和“印厂说已备好”，也注明了 PDF 和照片尚未收到。读者能看到哪些事项已有确认，哪些还需要补材料。

示例使用了已启用的方法。首次安装后，可以从自己的材料中提炼方法，试用并确认启用，再用于后续任务。
