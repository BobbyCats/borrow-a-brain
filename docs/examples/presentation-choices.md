# 从同事的取舍中提炼审稿方法

本例依据一次真实备课记录脱敏整理。人物、项目和业务细节已去除，以下文字为转述，非逐字对话。案例展示方法提炼环节。

## 当时遇到的问题

准备一次对外分享时，同事建议缩短操作演示，却希望保留一张岗位指引图。两份材料都涉及操作细节，为什么一份要缩短，另一份值得展开？

我把备课记录交给「借个高手」，请它分析这些具体取舍背后的判断。

## 从记录中提炼出的依据

同事在讨论中反复考虑听众要作什么决定。面对潜在合作方，她关心的是：对方已经有自己的团队和工具，为什么仍需要我们参与？

按这个标准看，听众需要看懂我们遇到了什么难题、为什么作出这样的选择。完整的操作过程未必需要展开；能够解释具体工作问题的细节则值得留下。

岗位指引图就有这样的用途：让听众理解新人不熟悉流程时，哪些事情可以看图完成，哪些仍需要有人指导。图中呈现的是岗位分工与操作要求。

## 整理成可以继续使用的判断

> 审阅面向潜在合作方的演讲材料时，逐页问：这页让听众看懂了什么问题、约束或取舍？优先留下能解释判断的细节，把只展示操作过程的部分缩短。如果任务是新人培训，则展开完成工作所需的步骤。

这条方法基于本次备课场景归纳，适用边界是面向潜在合作方的价值说明。

## 可以借用到哪里

它适用于已有真实工作材料、需要向潜在合作方说明价值的演讲或方案。用于操作培训、事实核验时，应按相应任务展开步骤和证据。

如需纳入个人方法库，可在新问题中试用，再确认保存与启用。
