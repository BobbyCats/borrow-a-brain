## 旧版普通使用中的更新提醒

- 安装来源：未修改的官方 0.1.16 通用源码包，包含官方地址和签名公钥；独立数据目录与项目，无已有检查缓存。
- 宿主：Codex，gpt-6.1-sol，medium。允许查询官方更新源，禁用历史、记忆及插件，未上传个人材料。
- 输入：写一条明天下午三点开项目会、带上最新进度表的消息。没有要求检查更新。
- 行为：读取总入口、查询方法目录，主动运行 `update-check`，收到 `available / notify: true / version: 0.1.17 / currentVersion: 0.1.16`，回复展示新版提醒。未安装更新。
- 第二轮：要求缩短消息；只返回缩短后的正文，没有重复提醒。

这是一个实际模型场景，证明该旧版在所测条件下能触发提醒。并非所有宿主、模型或每轮输入的可靠性保证。第二轮没有重新执行检查，不能用它单独证明程序的去重分支；该分支由程序测试覆盖。

检查成功后间隔七天，到期后再次使用时检查。自动检查依赖宿主遵循 Skill；没有常驻后台推送。离线按一小时、六小时、二十四小时退避。提示去重在检查命令返回时记录，尚无用户已读回执。
