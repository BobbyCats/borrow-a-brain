## 真实模型试用

使用已有 macOS Codex 账号，创建三个新会话，完成六轮交互。业务材料与人物方法均为虚构，保存在隔离目录；前两个窗口使用候选目录，第三个窗口使用升级后的全局安装。模型沿用宿主默认配置；不等于干净账号或普通新手试用。

| 场景 | 实际结果 |
| --- | --- |
| 从虚构访谈提炼，要求以后能用 | 保存带来源的方法草稿，执行新题和分支切换题；展示版本与确认摘要，未擅自启用 |
| 检查整个方法的禁用范围 | 独立评审指出培训题仍在方法分支内；补做心理判断和准确概率题，实际回答拒绝无依据推断，保存新版本 |
| 审阅具体版本后启用 | 测试主代理核对 v0003 后授权；目录和档案回读均显示此版本已启用。不是用户对真实业务效果的认可 |
| 另开会话，只给会面任务 | 自行查询目录、记录方法选择、读取 v0003，完成八分钟会面安排；未使用旧任务恢复命令 |
| 简报包含废弃 v1 和已确认 v2 | 采用 v2 的首次交流目标，未改成旧 AI 草案的现场培训或询问预算；准备时间限制也保留 |
| 全局安装升级后另开会话 | 实际加载全局 0.1.6，自动选用隔离库的 v0003。针对协会秘书长的新任务采用六分钟会面和十分钟准备，没有沿用另一任务的八分钟旧简报 |
| 切换到无关的群通知改写 | 重新查目录，判断现有方法不适用；直接输出简短通知，没有套用会面方法或新增文件 |
| 调用声明 | 进度区分待查和待加载，交付列出实际方法版本；与宿主格式合并，没有重复页尾声明 |

首次提炼窗口额外读取了一次旧全局入口，随后使用隔离目录的候选版本。没有读取默认个人数据，但不记为严格隔离零偏差通过。后续复用窗口允许读取宿主入口，实际使用候选目录；安装后的第三个新窗口使用全局 0.1.6 完成另一次自动选用。
