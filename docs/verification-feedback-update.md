1. 复用 `update-check` 查询已发送反馈。区分作者修复版本、可信可用版本和本机版本；只对实质变化提醒，不自动安装或发送。
2. 成功版本检查仍间隔七天；失败按一小时、六小时、二十四小时退避，成功清零。版本检查与反馈检查相互独立。
3. 针对性程序检查、现有回归检查和新会话实测通过后，正常安装到本机。方法库、记忆、授权、作者配置、公钥与既有规则保留。
4. 完成以上即结束本轮。范围外发现只记录；不扩模型消融、官网改版、备用镜像或自动修复代码。
