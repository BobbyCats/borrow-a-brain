# 0.1.11 验证记录

验证日期：2026-10-15。0.1.11 已作为体验版发布。GitHub、独立官网和本机正式包同步完成。

## 本版范围

改进「问到点上」的开放问题推导，合并重复收录提醒。程序实现、方法库格式、配置及保存、启用、发送和安装的确认边界保持不变。

## 已完成的行为验证

使用 `gpt-6.1-sol / medium`，以三道固定题比较已发布版与修订版。两轮均为两组、六段独立会话、十四轮输入。第二轮只合并重复收录提醒，题目不变；本次发布不重跑对照，也不追加题目。

修订版在第一道开放题中较早提出另一种因果解释，把容易成交与交付难度联系起来，最终行动仍与原版接近。第二题核心判断持平；第三题均直接完成执行请求。两个版本的事实、行动与边界检查均通过，未观察到未经确认的保存或启用。该结果支持采用小幅体验改进，不支持宣称稳定产生 Aha moment 或全面优于原版。

原定成本门未通过：第二题累计 token 多 53 个（约 0.055%），单次耗时增加约 45.6%；第一题工具调用也有增加。原始结果保留，不改报为通过。复核后认为单次耗时受缓存和服务波动影响，不能单独决定体验取舍，因此按实际推导价值采用当前修订。累计 token 包含缓存输入，不等于费用；本版没有普遍提速或减少所有读取的结论。
