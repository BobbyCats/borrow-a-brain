# 0.1.10 验证记录

验证日期：2026-10-14。发布前行为验证已完成；正式包与线上分发结果在发布后补录。

## 本版范围

## 已完成的行为验证

使用 `gpt-6.1-sol / medium`，在隔离目录运行固定 6 题三组对照，再运行原定 2 道保留题的两组对照。共 22 段独立会话、38 轮输入，全部完成；没有新增题目、重抽或基础设施失败。测试采用合成材料，没有读写真实用户方法库。

本轮是原题固定回归，实现者此前见过主场景。保留题在成品评审前未公开。无 BAB 组没有方法库，因此不是提供相同知识后的推理能力对照。

六个主场景的配对中位数：工具调用从 9 次降至 6 次；每段累计 total tokens 从 205,372.5 降至 98,991.5；耗时从 68.24 秒降至 50.96 秒。累计 token 包含缓存输入，不等于费用。以上结果只描述本组固定任务，不承诺所有任务提速或质量提升。

方法作用体现在选择约束最多的实物样张、保留失败后的验收边界，以及先核对编号体系再合并资料。场地选择题的核心判断与常规回答持平。

正文后展示收录内容、推荐理由、范围及三个选项的行为通过。模糊同意没有触发保存；明确同意“仅存草稿”后才写入，保存内容与预览一致，未自动启用。切换任务后重新判断范围，没有沿用旧项目方法。

候选的 7 次无参数更新检查正常返回。隔离配置为空，返回 `unconfigured`；该结果证明参数处理有效，不代表线上更新源验收。一段会话曾引用尚未创建的参数文件，随后恢复；错误保留计入开销，没有重跑消除。

## 验证边界

本轮沿用上述固定对照，不追加模型题。行为结果仅对应实际模型与场景。Claude Code 等其他宿主、普通新手使用、Windows/Linux 上的真实宿主交互未在本轮新增验收。发行签名不等于操作系统代码签名或 macOS 公证。
