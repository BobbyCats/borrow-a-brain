## 真实模型试用

共 18 次完成的真实 Codex 会话，覆盖 16 个场景编号。使用现有 macOS 账号、隔离项目、候选 Skills 与合成数据目录，不是干净账号。模型沿用宿主默认配置。两次图片参数错误在启动模型前失败，修正测试脚本后重跑，不计作模型会话。

| 场景 | 观察 |
| --- | --- |
| 活动准备时间不足 | 先问准备时间上限，未泛问人生目标 |
| 作品集与文章取舍 | 先明确各自用途，不替用户推荐偏好答案 |
| 取消通知 | 复测未把内部未知事项直接写给读者 |
| 短通知改写 | 实际查方法目录，只选一份方法并交付成品 |
| 无题材新人 | 直接给标明虚构的小例子与结果 |
| 视频字幕 | 保留时间点，明确未读原始音轨或画面 |
| 多人 Word 纪要 | 实际读文件；身份不明时不把 A/B 归给用户 |
| PDF 书页节选 | 实际读三页并保留印刷页码，不冒充整本阅读 |
| 白板照片 | 实际看图，区分不同说话人；复测不虚构用户的旧做法 |
| 图片与文字来自同次事件 | 不按两次行为累计，也不把他人意见归给用户 |
| 原始音频 | 工具缺失时说明内容未读；提供转写替代路径 |
| 素材库连续三步 | 入库 → 覆盖至 r0002 → 找回最新材料并保存未启用草稿 |
| 两项无 Skill 对照 | 复杂问题有更聚焦迹象；短改写的常规回答也可用且更短 |

不能据此声称 Skill 在所有任务都更好。这里只有两组配对，未盲评、未随机化，也没有普通新手参加。

## 失败与修复记录

- 取消通知首轮仍包含“退款安排尚未确定”。将受众内容规则前移到总入口后，复测修正。
- 看图试用中曾虚构“用户原来先做页面”的对照。补充不得虚构基线的入口规则后，复测修正。
- 图片测试脚本两次误把提示词当图片参数。加参数分隔后实际进入模型测试。这是测试工具错误，不能写成产品通过。
- 独立代码评审发现异常退出与清理失败的残留问题。已增加文件移动事务、登记清理与失败重试，并加入故障回归。最终只读复核未发现新增阻断问题。

## 能力边界

材料教程覆盖视频、音频、办公文件、PDF、书籍、会议、图片与混合来源。实际读取依赖宿主；本套件不附带通用语音转写、OCR 或视频解码服务。原始音视频成功解析、其他宿主、Windows/Linux 真实交互及普通新手上手仍未验收。

素材库目前按元数据检索，尚无全文或语义搜索。它保留一个当前受管副本与版本记录；更新不保留旧全文。方法里的必要摘录和旧版本说明仍存在，删除素材不能称为彻底遗忘所有派生内容。
