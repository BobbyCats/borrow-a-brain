# 借个脑子：开始使用

把这一段连同解压后的文件夹交给你正在使用的 AI：

> 帮我安装这个文件夹里的“借个脑子”。先看我的应用和系统，告诉我会装在哪里、增加什么规则。保留我原来的配置。装好后，带我用一件小事试一次。

你不需要 GitHub 账号。文件夹里有五个 Skill、中文说明和本地程序。安装后，你的个人资料保存在自己的电脑上。

## AI 按这几步安装

1. 确认这是 Codex 或 Claude Code 的本地环境。只看必要目录和程序版本，不读取私人聊天。其他应用先核对是否支持本地 Skill、文件和命令执行。
2. 有 Node.js 22+ 时运行 `node skills/bab/scripts/run.mjs help`。独立程序包运行 `skills/bab/bin/bab help`；Windows 为 `bab.exe`。命令中的相对路径需换成当前包的实际绝对路径。
3. 运行 `setup codex 项目绝对路径` 或 `setup claude 项目绝对路径`。先展示预览中的安装位置、完整规则、数据目录与冲突情况。用户明确要求所有项目都能使用时，用 `--user` 代替项目路径。不能自行扩大到全局。
4. 用户确认后，在相同命令后加 `--apply`。有既有安装时沿用已登记路径；非标准目录使用 [本地操作](../skills/bab/references/operations.md) 中的 install JSON 方式。不要复制第二份来绕过冲突。
5. 在该项目的新会话里说：“我有件事拿不定主意，你帮我捋一捋。”检查 AI 是否显示实际调用并开始帮助。脚本写入成功不等于宿主加载成功。

首次使用先完成当前小任务。不要先读用户的十个历史会话。需要历史、持久记忆或发送反馈时，再说明具体范围。

## 装好了，下一句说什么

打开包内 [三次上手练习](../skills/bab/assets/getting-started.md)。它包含完整的虚构材料，你可以直接复制。学会一次后，换成自己的事即可。

| 如果遇到 | 让 AI 这样处理 |
| --- | --- |
| 找不到命令或没有调用提示 | 查实际安装路径、同名 Skill、宿主加载设置；重新开该目录的会话 |
| 安装程序打不开 | 核对系统与处理器；不匹配时改用 Node.js 源码包，不关闭系统保护 |
| 程序提示“本地有修改” | 显示差异，先保留你的修改，不删资料重装 |
| 当前应用只能网页聊天 | 先贴材料体验；本地记忆、自动读历史和安装维护暂不可用 |
| 想卸载 | 用原下载包运行 uninstall，移除代码与路由；个人资料另行决定是否清除 |

## 你可以随时控制记录

说“你记了我什么”“这条只用于写工作报告”“这次别用老王”“把这条忘掉”即可。

更新前，AI 应告诉你这版改了什么。反馈前，AI 应展示完整正文和收件地址。没有收到你的同意，不能发送。

本地保存不代表模型完全离线；发给 AI 的材料仍按你所用应用的数据处理规则运行。程序签名更新只验证作者发布包的完整性，不等于 Apple 公证或 Windows 程序签名。
