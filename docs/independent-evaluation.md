# 独立试用记录

2026-10-05。评测代理已获用户授权。只使用虚构材料，安装与状态位于隔离目录，没有读取真实聊天或改动用户全局配置。

## 已完成的基线与复测

0.1.1 的四个 Codex CLI 新会话中，“学同事的方法”和“从给定记录认识自己”没有读取对应 Skill。方法学习只给了消息成品，缺少方法卡与边界。直接改写没有被强制访谈。

0.1.2 已完成四个新会话试用：

| 场景 | 观察到的行为 |
| --- | --- |
| 学同事办法，同时要一条可发消息 | 实际读取 bab → bab-pro 与流程；交付消息、方法卡、来源与类推区别、适用边界；未保存 |
| 只看三条虚构记录，判断选择习惯 | 实际读取 bab → bab-me 与流程；区分用户选择与 AI 建议，注明样本有限且未保存 |
| 不提供 taskId，说“接着上次那条” | route-list → route-load 找到先前合成任务，恢复两份 v0001 方法和进度，交付短消息，没有外发 |

恢复测试的初始档案与进度由评测者按 Skill 流程准备。另一个全新亲子陶艺课通知任务未给人物名或角色提示，实际执行 bab → routing → operations → context → route-catalog → route-save → profile-get → 成稿。模型从两份方法中选择一份作为主责，没有为凑数加载另一份。

两类证据分别证明自动选用一份适合的方法，以及恢复并使用两份方法。没有据此宣称所有任务都会选对专家。

还发现并修复：预览缺完整规则、非主责 role 枚举未说明、误运行 cli.mjs 模块、macOS 路径别名使同范围任务查不到。后两项分别增加明确运行入口与 context 命令。

## 证据与限制

真实宿主为 Codex CLI 0.160.0，使用 `exec --ephemeral --ignore-user-config` 和隔离项目。现有宿主仍可能注入全局 Skill / 规则；此测试不是完全干净账户的测试。

模型按规则试用与程序约束测试分别记录。两份方法由同一 Agent 顺序使用，没有声称启动两位独立专家。原始 JSONL、提示与输出保留在本次本地验收目录；它们不随用户分发包打包。

未做：五位普通用户独立上手、Claude Code 真会话、Windows/Linux 的真实宿主交互、所有模型和所有自然表达的统计准确率。
