# 借个脑子 · Borrow a Brain

**把别人的经验和自己的好做法，变成 AI 下次还能用的方法。**

借个脑子是一套中文 AI Skills。把访谈、书籍、会议记录或工作经验交给 AI，它会提炼做法，用你的问题试用，再由你决定是否保存和启用。以后遇到适合的任务，AI 会从已启用的方法中选用，不必每次点名。

提供 Codex 和 Claude Code 安装入口。Codex 已完成部分对话试用；Claude Code 的实际交互仍在验证中。

[安装](https://jclab.work/tools/borrow-a-brain/#start) · [使用指南](docs/quickstart.md) · [更新记录](CHANGELOG.md) · [GitHub Releases](https://github.com/BobbyCats/borrow-a-brain/releases)

## 能做什么

- **学别人的方法**：从材料中整理判断依据、做事步骤和适用条件，用你的问题试一次。
- **整理自己的经验**：从你选定的对话和复盘中找出习惯与偏好，确认后保存。
- **一起想清难题**：检查现有解释，从材料中寻找新的联系；需要作选择时，给出推荐和理由。
- **复用已启用的方法**：写方案、改消息、做判断时，查找适用的方法，并说明实际用了哪一份。

装好就能提问、分析材料和提炼方法。自己的方法库会随着确认收录逐渐积累，也可以先请 AI 带你做一次上手练习。

## 一个真实的提炼案例

**同样是操作细节，为什么删掉这一段，却留下另一张图？**

准备一次对外分享时，同事建议缩短操作演示，却希望保留一张岗位指引图。我把备课记录交给「借个高手」，想弄明白这两次取舍背后的判断。

从记录中提炼出的依据是：先考虑听众要作什么决定。面对潜在合作方，听众已经有自己的团队和工具，需要看懂我们解决了什么难题、为什么作出这样的选择。

完整的操作过程可以缩短。岗位指引图则能把一个工作问题讲具体：新人不熟悉流程时，哪些事可以看图完成，哪些仍需要有人指导。

据此整理出一条审稿方法：**这页材料，能让听众看懂我们解决了什么问题、作出了什么取舍？** 如果下次做新人培训，就重新展开操作步骤。

本例依据真实备课记录脱敏改写，非逐字对话。方法已完成提炼，尚未入库或启用；本例不展示后续自动复用的效果。

## 安装

需要能读写本地文件、执行命令的 AI 应用。

1. 从 [官网](https://jclab.work/tools/borrow-a-brain/#start) 下载安装包并解压。
2. 在 Codex 或 Claude Code 中提供解压后的文件夹，输入：

   > 帮我安装这个文件夹里的“借个脑子”。先告诉我装在哪里、改哪些文件，保留原来的配置。

3. 确认安装预览后，在所选项目中新开会话。可以说“带我做一次上手练习”，也可以直接提供材料和要解决的问题。

安装会添加五个 Skill，并在 `AGENTS.md` 或 `CLAUDE.md` 中加入自动调用说明。默认用于一个项目；希望所有项目都能用时，说明“安装到用户级”。

Apple 芯片 Mac、Windows x64 和 Linux x64 的独立包自带运行程序。源码包需要 Node.js 22+。首次安装请选择官网或 Release 附件中的安装包；GitHub 自动生成的 Source code 是仓库快照。

[命令行安装与环境要求](docs/quickstart.md) · [怎样提供文件、视频和其他材料](skills/bab/assets/materials-guide.md)

## 保存和复用方法

你可以主动说“把刚才这个办法整理下来，先给我看”。AI 也会在日常任务中发现有依据、可复用的做法，提出收录建议。

1. 先完成当前任务，再展示方法内容、适用条件、推荐理由和保存范围。
2. 由你选择保存为草稿、修改后再存，或这次不存。
3. 用新问题和不适用的场景试用，经你确认后启用。
4. 后续遇到适合的任务，AI 从已启用的方法中选用。

保存草稿不会自动启用。没有回复不会自动入库。主动收录只使用当前获准读取的内容，不在后台扫描聊天。

收录时，AI 会根据方法内容建议保存范围。能跨项目复用的做法，优先建议个人通用；依赖项目资料或约定的做法，建议项目专用。具体范围由你确认，已有方法不会自动改变。

方法集中保存在本机，保存时可选择使用范围：**个人通用**的方法可在各项目中选用，**项目专用**的方法只用于指定项目。AI 从个人通用和当前项目已启用的方法中判断是否适用，无需把方法文件复制到每个项目，也不要求先整理电脑里的文件夹。查询提示会注明本次查看的范围。尚未收录方法时，提问、材料分析和方法提炼照常可用。

## 五个入口

平时直接说需求即可，也可以点名使用。

| 名称 | Skill 名称 | 用途 |
| --- | --- | --- |
| 借个脑子 | `bab` | 理解任务，选择流程和方法 |
| 借个高手 | `bab-pro` | 提炼并试用他人的方法 |
| 懂我一点 | `bab-me` | 整理自己的经验与偏好 |
| 问到点上 | `bab-ask` | 提出问题，分析选择，寻找新思路 |
| 带我上手 | `bab-help` | 安装、教程、更新与反馈 |

例如，在支持 `$` 调用的应用中输入 `$bab-help 带我试一次`。具体调用形式以所用应用为准。

## 更新与反馈

说“检查借个脑子有没有更新”即可。找到新版后，AI 会说明变化，经你同意再安装。升级保留方法、记忆、素材和本地配置；本地文件存在手工修改时，会先提示冲突。

日常使用也会按间隔检查更新。检查失败后，在后续使用时重试。详细行为见 [更新与反馈流程](docs/improvement-cycle.md)。

遇到问题可以说：

> 把刚才的问题整理给作者，先让我看内容。

AI 会整理问题和复现步骤，你确认正文和接收地址后才发送。后续有处理进展或可用的修复版本时，会提示你查看。

## 数据与支持范围

资料保存在本机，与程序分开。读取旧对话前会确认范围；已保存内容可以查看、修改或删除。交给 AI 的材料仍按所用应用的数据处理规则处理。

当前为预览版。自动选用方法和主动收录的表现会因模型而异。独立程序尚未完成 macOS 公证或 Windows 代码签名。
