# 借个脑子 · Borrow a Brain

**借别人的思路，理自己的难题。**

借个脑子是一套中文 AI Skills，用来提炼人物方法、整理个人经验、梳理决策。你可以把文章、访谈或对话交给 AI，将其中的做事方法保存下来，在后续的写作、沟通和分析中继续使用。

[官网与下载](https://jclab.top/tools/borrow-a-brain/) · [使用指南](docs/quickstart.md) · [更新记录](CHANGELOG.md)

## 安装

需要能读写本地文件、执行命令的 AI 应用。提供 Codex 和 Claude Code 安装入口。

1. 从 [官网下载](https://jclab.top/tools/borrow-a-brain/) 适合系统的安装包，解压到本地。
2. 在 AI 应用中打开或提供这个文件夹，输入：

   > 帮我安装“借个脑子”。先告诉我会装在哪里、改哪些文件，保留我原来的配置。

3. 确认安装后，在所选项目中开启新会话。

安装程序会添加五个 Skill 和自动调用规则。也可以 [通过命令行安装](docs/quickstart.md#命令行安装)。

## 使用

直接说你要做什么。AI 会根据当前任务选择 Skill，并在回复中显示实际调用的名称。

| 你想做的事 | 可以这样说 |
| --- | --- |
| 学会别人的方法 | “这篇访谈里，他是怎么判断的？帮我整理成以后能用的方法。” |
| 复用已保存的方法 | “用老王的方法，帮我看看这份方案。” |
| 了解自己的习惯 | “看看我最近的对话，我总是在纠结什么？” |
| 理清一个选择 | “我想做这件事，但没想清楚。你来问我。” |
| 获取帮助 | “借个脑子怎么用？带我试一次。” |

“老王”是示例名称，使用前需要先建立对应的方法档案。可以先用 [三次上手练习](skills/bab/assets/getting-started.md) 中的示例材料体验；0.1.2 及以上安装包也附带这些练习。

### 五个 Skill

| Skill | Codex 命令 | 用途 |
| --- | --- | --- |
| 借个脑子 | `$bab` | 按任务选择流程和已保存的方法 |
| 借个高手 | `$bab-pro` | 从材料中提炼方法，试用后保存为人物档案 |
| 懂我一点 | `$bab-me` | 从获准读取的记录中整理习惯与偏好，由你确认后保存 |
| 问到点上 | `$bab-ask` | 逐步追问关键问题，给出推荐选项和理由 |
| 带我上手 | `$bab-help` | 使用指导、更新、反馈和数据管理 |

`bab` 是 Borrow a Brain 的缩写。以上是 Codex 的手动调用写法；其他应用的入口以应用自身为准。自动调用需要应用加载安装时写入的规则。

### 方法可以积累，也可以组合

每个人物有独立的方法档案，记录判断步骤、材料来源和适用条件。AI 会先用新问题试用提炼结果，经你确认后启用。之后可以补充材料、修订版本、回退或删除，也可以导出为独立 Skill。

你可以点名使用某个人的方法，也可以直接提出任务。AI 会从已启用的档案中选择适用的方法。例如写一份方案时，用一份方法组织结构，再用另一份检查论据。一次任务最多选用三份方法，最后交付一份完整结果。

## 环境与隐私

- **AI 应用**：完整功能需要本地文件和命令执行权限。Codex 已完成部分交互场景验证；Claude Code 提供安装支持，交互兼容性仍在测试。
- **运行环境**：独立程序包支持 macOS Apple 芯片、Windows x64 和 Linux x64；源码包需要 Node.js 22+，无需安装 npm 依赖。
- **本地数据**：人物档案、个人记忆和授权记录与程序分开保存。更新和卸载默认保留这些数据。交给 AI 的材料仍受所用应用的数据处理规则约束。
- **历史与反馈**：读取历史前确认范围；反馈发送前展示正文和接收地址。原始聊天不会自动上传给作者。
