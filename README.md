# 借个脑子 · Borrow a Brain

**借别人的思路，理自己的难题。**

看到一个好办法，想学会却总是用不上；反复向 AI 解释自己的要求，下次还得重说；眼前有几个选择，又不知道从哪里开始。

借个脑子是一套中文 AI Skills。你说手头的事，AI 按任务选择方法，和你一起把事情做完。

[官网与下载](https://jclab.top/tools/borrow-a-brain/) · [使用指南](docs/quickstart.md) · [更新记录](CHANGELOG.md)

## 先看看，你能拿到什么

| 你想做什么 | 你提供什么 | 你能拿到什么 |
| --- | --- | --- |
| 学会别人的方法 | 一段访谈、几页书、一次会议或一个案例 | 有依据、能试用的做事方法；确认后可留下次用 |
| 少一点反复解释 | 你选定的复盘、对话、方案修改记录 | 带场景的习惯与偏好；由你确认、修改或删除 |
| 把选择想清楚 | 正在犹豫的事、已知条件 | 关键取舍、有理由的建议和能执行的下一步 |

不必记住命令。装好后，可以直接复制下面这段试一次。例子是虚构的，不需要准备私人资料：

> 小周催合作方时会说：“周五要交，周四前需要拿到图片。你今天能给，还是明早能给？如果明早不行，我就先用旧图排版。”我想学他的办法。现在我要请师傅明天下午三点前确认柜子的尺寸，帮我写一句。不要替我编造承诺，先别保存。

你应该先得到一句能用的话，再看清这一招怎么用。AI 应把示例里的方法和自己补充的建议分开。满意后可以说：“把这招整理成方法草稿，用新问题试试，再给我确认。”

更多练习：[先用一次，再记名字](skills/bab/assets/getting-started.md)。

## 怎么安装

需要能读写本地文件、执行命令的 AI 应用。提供 Codex 和 Claude Code 安装入口。

1. 从 [官网](https://jclab.top/tools/borrow-a-brain/#start) 下载适合电脑的安装包，解压。
2. 在 AI 应用中提供解压后的文件夹，输入：

   > 帮我安装“借个脑子”。先告诉我会装在哪里、改哪些文件，保留我原来的配置。装好后带我试一次。

3. 检查安装预览并确认。在所选项目中新开会话，试上面的小任务。

安装会添加五个 Skill 和自动调用规则。回复开头会显示实际用到的入口或方法。默认先用于一个项目；需要所有项目都能用时，说明“安装到用户级”。[完整步骤与命令行入口](docs/quickstart.md#命令行安装)。

Apple 芯片 Mac、Windows x64、Linux x64 可用自带程序的安装包。通用源码包需要 Node.js 22+，无需安装 npm 依赖。

## 手里有文件，直接从文件开始

把原文件交给当前 AI 应用，或提供它能访问的链接。补一句：想学谁的什么办法，准备用在哪里。多人材料说明谁是谁。

> 这是访谈视频和几张书页照片。我想学他怎么决定先做什么，用来安排本周任务。先告诉我读到了哪些部分，再提炼一个方法，用在我这周的安排上。先不要保存。

[素材提供指南](skills/bab/assets/materials-guide.md) 覆盖八类材料，每类都有可复制的说法：

- 视频、课程和访谈。
- 音频、播客和语音日记。
- PDF 与扫描文件。
- 书籍章节、电子书与书页照片。
- Word、幻灯片和表格。
- 会议纪要与多人会议记录。
- 照片、截图、白板和手写笔记。
- 来自同一件事的混合资料。

实际可读的格式由当前 AI 应用及其工具决定。读不到时，补字幕、转写、相关页或清晰片段即可。只有字幕时就分析话里的方法，不把它当作看过视频画面。提供材料本身不代表同意长期保存。

## 收藏、更新、找回

想长期使用材料，可以说：

> 把这份纪要存进我的素材库，标题叫“一月项目取舍会议”，加上“项目取舍”标签，只用于当前项目。

原件留在原处，库内保存一个当前副本。同一范围内相同内容去重；更新时替换库内旧文件并增加版本号。依赖旧材料的方法和记忆会暂停自动调用，复核新材料后再恢复。

以后直接说：

- “找一下素材库里关于项目取舍的会议资料。”
- “这是那份纪要的新版，更新原来的素材。”
- “用最新材料重新检查之前的方法，给我看变化。”

目前按标题、别名、原文件名、标签和类别查找，不提供全文或语义搜索。删除素材只删除库内副本；如需连派生的方法与记忆一起删除，请说明范围。

## 方法留下来，后面的事接着做

安装包没有预装真人档案。你提供材料，AI 提炼、试用，你确认后启用。以后可以点名使用，也可以直接说任务，让 AI 选择已经启用且适用的方法。

| 你说 | 会做什么 |
| --- | --- |
| “用刚才保存的方法，看看这份新方案。” | 调用已启用的方法，并说明适用处 |
| “看看这几次复盘，我做选择时有什么习惯？先别保存。” | 区分事实与推断，不把他人的建议算成你的习惯 |
| “这条可以记住，只用在安排旅行时。” | 保存你确认的、有使用范围的记忆 |
| “接着上次没做完的事。” | 查找同范围内已保存的任务进度 |
| “你记了我什么？把这一条忘掉。” | 回读记录，删除指定条目 |

## 五个入口，不用背

| 名称 | 做什么 |
| --- | --- |
| 借个脑子 | 理解任务，选择流程与已保存的方法 |
| 借个高手 | 从材料提炼做事方法，试用后保存 |
| 懂我一点 | 梳理你的经验与偏好，确认后记住 |
| 问到点上 | 找到具体卡点，比较选择并推进下一步 |
| 带我上手 | 安装、教程、更新、反馈与数据管理 |

## 更新、环境与资料

- **更新**：说“检查借个脑子有没有更新”。看过变化并同意后安装，人物档案、记忆、素材与原有规则保留。
- **宿主**：Codex 已验证部分真实交互场景；Claude Code 提供安装支持，真实交互仍需验证。文件安装成功与应用已加载是两件事。
- **本地保存**：资料与程序分开保存。交给 AI 的内容仍按所用应用的数据处理规则运行，本地保存不等于完全离线。
- **反馈**：说“把这个问题整理给作者，先让我看”。确认正文和接收地址后才发送，不自动上传原始聊天。
- **卸载**：移除程序与规则，默认保留个人资料。需要清除资料时单独说明。
