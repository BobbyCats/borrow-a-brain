# 借个脑子 · Borrow a Brain

**把别人的经验和自己的好做法，变成 AI 下次还能用的方法。**

借个脑子是一套用于 Codex、Claude Code 的中文 AI Skills。它从你提供的材料中提炼方法，帮你分析问题、完成任务，再由你决定哪些方法值得留下。方法启用后，AI 可以按任务选用，不必每次点名。

[下载与安装](https://jclab.work/tools/borrow-a-brain/#start) · [使用指南](docs/quickstart.md) · [更新记录](CHANGELOG.md) · [GitHub Releases](https://github.com/BobbyCats/borrow-a-brain/releases)

## 能做什么

- **学别人的方法**：从访谈、书籍、会议或案例中提炼判断依据、做事步骤和适用条件，用你的问题试一次。
- **整理自己的经验**：从你选定的对话和复盘中找出习惯与偏好，逐条确认后保存。
- **理清眼前的选择**：追问会影响决定的问题，给出推荐选项和理由，推进到下一步。
- **复用已经验证的方法**：写方案、改消息、做判断时，自动查找当前范围内适用的方法，并说明实际用了哪一份。

首次安装的方法库为空。方法来自你提供的材料和日常工作，保存与启用都由你确认。

## 安装

需要能读写本地文件、执行命令的 AI 应用。

1. 从 [官网](https://jclab.work/tools/borrow-a-brain/#start) 下载安装包并解压。
2. 在 Codex 或 Claude Code 中提供解压后的文件夹，输入：

   > 帮我安装“借个脑子”。先给我看安装位置和配置变化，保留原来的配置。装好后带我试一次。

3. 确认安装预览后，在所选项目中新开会话。

安装会添加五个 Skill，并在 `AGENTS.md` 或 `CLAUDE.md` 中加入自动调用说明。默认安装到一个项目；希望所有项目都能用时，说明“安装到用户级”。

Apple 芯片 Mac、Windows x64、Linux x64 的安装包自带运行程序。其他架构可使用通用源码包，需要 Node.js 22+，无需安装 npm 依赖。

命令行安装、环境要求和故障处理见 [使用指南](docs/quickstart.md)。GitHub 自动生成的 Source code 是仓库快照；首次安装请选择官网或 Release 附件中的安装包。

## 试一次

下面是一个虚构例子，可以直接复制：

> 同事小周催进度时，先说要对方确认什么，再给期限，最后说来不及时怎么处理。我想学他的办法。现在我要请师傅明天下午三点前确认柜子的尺寸，帮我写一句。没有确定的安排别替我编，先别保存。

AI 应先给出能直接使用的消息，再解释从材料中提炼的方法和适用条件。你可以继续说：

> 把这个方法整理成草稿，用一个新问题试试，再让我确认是否启用。

启用后，换一个任务直接说“帮我写一句催客户确认样品的消息”即可。AI 会判断方法是否适用；有多份方法时，最多组合三份，分别负责不同部分。回复开头会说明实际调用的 Skill 与方法。

也可以直接提供自己的文件或链接。支持读到什么，取决于当前 AI 应用；详见 [素材提供指南](skills/bab/assets/materials-guide.md) 和 [三次上手练习](skills/bab/assets/getting-started.md)。

## 方法如何留下来

你可以主动要求保存。日常工作中，AI 也会根据具体纠正或有依据的做法提出收录建议。

1. **先完成任务**，再展示方法内容、适用边界、推荐理由和保存范围。
2. **确认后保存草稿**。你可以选择保存、修改后再存，或这次不存。
3. **用新问题和不适用的场景试用**，经你确认后启用。
4. **后续按任务选用**。有新证据时修订原方法，并保留版本记录。

保存草稿不等于启用。没有回复不会自动入库。主动发现只使用当前已经获准读取的内容，不在后台扫描聊天。

## 五个 Skill

平时直接说需求即可，也可以点名使用。

| 名称 | Skill 名称 | 用途 |
| --- | --- | --- |
| 借个脑子 | `bab` | 理解任务，选择流程和方法 |
| 借个高手 | `bab-pro` | 提炼并试用他人的方法 |
| 懂我一点 | `bab-me` | 整理自己的经验与偏好 |
| 问到点上 | `bab-ask` | 追问关键问题，比较选择 |
| 带我上手 | `bab-help` | 安装、教程、更新与反馈 |

例如，在支持 `$` 调用的应用中输入 `$bab-help 带我试一次`。具体调用形式以所用应用为准。

## 更新与反馈

说“检查借个脑子有没有更新”，AI 会展示新版本的变化，经你同意后安装。官方安装包配置了签名更新源；使用时由 AI 发起检查，程序按每份安装至少间隔 7 天限频。它不会在后台定时运行，手动检查可以跳过间隔。

升级校验签名与文件内容，保留方法库、记忆、素材和本地配置。检测到安装文件被手工修改时，会停止覆盖并提示处理。

遇到问题可以说：

> 把刚才的问题整理给作者，先让我看内容。

AI 整理预期、实际结果和复现步骤。你确认完整正文和接收地址后才发送。作者处理后，你可以查询进展与修复版本。发布新版不代表每一条反馈都已解决。

## 数据与支持范围

资料保存在本机，与程序分开。读取旧对话前会确认范围；你可以随时查看、修改或删除已保存内容。交给 AI 的材料仍按所用应用的数据处理规则处理，本地保存不等于完全离线。

当前为预览版。Codex 已完成部分真实对话测试；Claude Code 提供安装支持，实际交互仍待验收。自动选用和主动收录依赖模型执行指令，不同模型的表现会有差异。独立程序尚未完成 macOS 公证或 Windows 代码签名。
